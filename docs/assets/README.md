# 原型预览素材

`agent-matrix-prototype.gif` 来自 `/codex/prototype` 的虚构会话回放，不包含真实运行日志。

更新方式：

1. 启动 `npm run dev`，在浏览器打开 `/codex/prototype`。
2. 点击“回放链路”，录制“运行全景”区域，保留输入、上下文、提示词、模型、执行环及观测层。
3. 将截图帧裁剪到同一区域，以原始采样间隔编码循环 GIF；建议宽度 800px，文件保持在 10 MB 以下。
4. 检查 GIF 确有多帧变化，所有内容均为演示会话；README 使用相对路径嵌入。

当前素材：800 × 785，36 帧，约 34 秒。截图和编码使用的浏览器及 Pillow 仅为文档制作工具，不是应用运行依赖。
